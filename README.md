# WebLLM Wrappers

This repository contains various wrappers for using the [MLC WebLLM](https://github.com/mlc-ai/web-llm) library in different frameworks.

## Available Wrappers

- [React](https://github.com/mlc-ai/web-llm-wrappers/tree/main/apps/sandbox-react)
- [Vue3](https://github.com/mlc-ai/web-llm-wrappers/tree/main/apps/sandbox-vue3)
- [Svelte](https://github.com/mlc-ai/web-llm-wrappers/tree/main/apps/sandbox-svelte)
- [Solid](https://github.com/mlc-ai/web-llm-wrappers/tree/main/apps/sandbox-solid)
- [Angular](https://github.com/mlc-ai/web-llm-wrappers/tree/main/apps/sandbox-angular)(experimental)

## Usage

Each wrapper has a README file that provides instructions on how to use it.
